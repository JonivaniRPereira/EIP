# Identidade visual JP Code Craft

Aplicada em 19/10/2026 a partir do [site indicado pelo usuário](https://www.jpcodecraft.com.br/),
conferido no navegador e em seu CSS público atual.

- Fundo papel `#f7f7f2`, verde `#285b45`, texto `#183b32` e bordas `#d5dbd2`.
- Títulos editoriais em Georgia; interface em Arial e ícones locais.
- Logotipo oficial em arquivo local, no menu, cabeçalho compacto e telas de acesso/organização.
- Tema Material, botões, seleção, gráficos e detalhes das integrações alinhados à paleta.
- Rodapé compartilhado em todas as rotas, com ano automático, direitos reservados e
  “Desenvolvido por JP Code Craft Solutions”, com link para o site.

O logotipo veio de `https://www.jpcodecraft.com.br/assets/img/jp-code-craft-logo.png`.
O favicon E é um SVG próprio da EIP nas cores aplicadas. As páginas não dependem
do site da marca para carregar os arquivos; os links externos abrem com `noopener noreferrer`.

Validação: 33 testes do frontend aprovados, build de produção e verificação de
fontes/licenças locais aprovados. Conferência visual de login, painel largo/compacto,
menu compacto, navegação para integrações e rodapé em página longa. O painel
permanece com receita 11.110 BRL. Nenhuma alteração de API/dados nesta atividade.
